# 📦 Legacy Prototype Archive

This directory archives early prototype scripts and monolithic files created during initial development:
- `agent.html`: Original monolithic HTML layout
- `appDataBase.py`: Original monolithic Flask backend
- `setup_Db.py`: Original database initialization script
- `create_user.py`, `automation.py`, `AutomationsNotifications.py`: Early automation experiments

## 🚀 Active Production Architecture
For running, modifying, or deploying the application, use the structured modular components:
- **`backend/`**: Modular Flask API, Agentic Engine, and Database models
- **`frontend/`**: Decluttered Single-Page Application (HTML5, Tailwind CSS, Modular JavaScript)
- **`run.py`**: Single-command launcher (`python run.py`)
